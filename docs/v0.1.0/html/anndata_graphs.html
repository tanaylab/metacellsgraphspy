anndata_graphs 

Graphs of a metacells AnnData (e.g., read from an h5ad file).

These are the AnnData counterparts of some of the Daf graphs. They are implemented in Python only, using the anndata_data_sources . Each obs entry is a metacell, each var entry is a gene, and X holds the fraction of the UMIs of each metacell in each gene.

metacellsgraphspy.anndata_graphs. ad_gene_gene_graph ( adata , * , x_gene , y_gene , entries = None , gene_fraction_regularization = None ) [source] 

The expression of x_gene against y_gene , a point per each of the entries of the adata , on log scale. This is the AnnData counterpart of gene_gene_graph() .

Parameters :

  • adata ( AnnData )

  • x_gene ( str )

  • y_gene ( str )

  • entries ( ndarray | Sequence [ str ] | Sequence [ int ] | None )

  • gene_fraction_regularization ( float | None )
