data_sources 

Data sources for the graphs of a metacells repository. See the Julia documentation for details.

A data source fetches data from a Daf repository (or a pandas frame) and writes it into the data source views of a somegraphspy graph. The get_ functions fetch and return the data, the put_ functions write data you already have into the sinks , and the fill_ functions do both. The sinks are any graph struct (a view, or one of the data or configuration structs a view holds), or a sequence of them.

Indices are 1-based, as in Julia: the entries and genes given by index, the indices of the low level queries, and the gene indices returned by the gene selection functions.

metacellsgraphspy.data_sources. EMPTY_TYPE_COLOR : str = 'magenta' 

The color to give to entities without any type annotation. See the Julia documentation for details.

metacellsgraphspy.data_sources. Entries 

Which entries of an axis a data source uses: their names, or their (1-based) indices.

alias of ndarray | Sequence [ str ] | Sequence [ int ]

metacellsgraphspy.data_sources. GENE_FRACTION_REGULARIZATION_FOR_GRAPHS : float = 1e-05 

The regularization added to a gene fraction before taking its log. See the Julia documentation for details.

metacellsgraphspy.data_sources. MAX_FOLD_FOR_GRAPHS : float = 3.0 

The extreme of the color scale of the log-base-2 fold factors between gene expression and median gene expression. See the Julia documentation for details.

metacellsgraphspy.data_sources. Via 

A chain of axes to walk before asking for a property (e.g., ["metacell"] to ask for the block of the metacell of each cell).

alias of Sequence [ str ]
